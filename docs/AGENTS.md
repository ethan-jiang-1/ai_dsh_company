# AGENTS.md — 文档层的规范

> 什么时候读：写/改/搬 `docs/` 下的文档、判断某事实该住哪层时。

本文件是 `docs/` 的**分层规矩唯一家**：哪层放什么、**哪层不放什么**、写多长、写完了怎么更新。
文档地图 = [index.md](./index.md)；决策台账 = [decisions.md](./reference/decisions.md)；写作风格（一次一句、不复述代码）= 根 [AGENTS.md](../AGENTS.md) 纪律表。
**本文件管形状，不管事实**——各主题的现在时语义住各合同文件，本文件不复述。

## 一处事实一个家

每个事实住**该管它的那一层**；别处只链接，不复述。判定次序：先定位该事实属于哪层 → 定该层的详略上限
→ 再看是教程（按前置顺序带读者到结果）还是参考（定义查得到的当前行为，无教学顺序）。

| 层 | 目录 | Job（这层管什么） | **不属于这层** |
|---|---|---|---|
| 导航 | [index.md](./index.md) | 文档地图（决策台账路由 = [decisions.md](./reference/decisions.md)） | 决定正文、理由、输掉的方案（→ Note）；主题事实（→ 该主题的合同） |
| 参考 | [reference/](./reference/) | 查表与登记：D 号、术语、外部材料 | 决定正文（→ Note）；主题事实（→ 合同） |
| 政策 | [policy.md](./policy.md) | **常设规则**：授权边界、门禁升格、自动化上限、越界写入、自主协议 | 操作步骤与命令（→ 指南）；机制依据（→ notes/implemented）；决定史（→ Note） |
| 指南 | `guides/` | **怎么操作**：runbook、查表步骤、环境怎么立 | 机制依据（→ notes/implemented）；枚举型清单（→ 实现自己，见 D28）；完成定义（→ `.agents/skills/` 或该面 owner）；常设禁令（→ 政策层） |
| 合同 | 顶层跨面宪法（[testing](./testing.md) / [repo-hygiene](./repo-hygiene.md) / [content-charter](./content-charter.md)）+ [contracts/](./contracts/)（按主题） | **是什么**：某主题/子系统**现在时**语义，随代码同 diff | 历史决策（→ Note）；迁移计划；未来设想 |
| 常驻入口 | [orient.md](./orient.md) | 驾驭者白话七问，只导航 | 任何事实的复述 |
| 规范 | [AGENTS.md](./AGENTS.md) | 文档层自身的分层、长度与更新规矩 | 主题事实（→ 合同层）；操作步骤（→ 指南） |

**「理由」的边界**：为什么选 A 不选 B、输掉的方案、验证证据 → `notes/implemented/`（Agent Note）；
`docs/` 只留当前语义（合同）、操作（指南）、查表（参考）；理由正文不再在 docs 留一份。

## 长度：顶点即信号

行数上限唯一源 = [`checks/gates/doc-budget.mjs`](../checks/gates/doc-budget.mjs) 的 `DOC_LINE_BUDGETS`（本文件不复述数字）。
语义 = **棘轮**：

- 只降不升——瘦身轮后上限随内容下调；上限长期高于内容 20% 由反向棘轮报红。
- 顶格 = 该面**常驻层饱和**的实测信号，处置是**瘦身**（把内容搬到该去的家），不是提额。
- 确需空间才在 Note 里论证后上调；「先提额再写」是反序。

文档超限时的处置次序：**① 搬**（内容属于别层 → 迁过去，原处留一行指针）→ **② 压**（确属本层但可更短）→
**③ 提额**（只有前两步都不成立才考虑，且须 Note 论证）。

## 更新时机

- **合同层**：随代码**同 diff** 更新。改了行为没改合同 = 谎报（合同说的不是现在时）。
- **指南层**：随操作方式演进更新；步骤变了就改，别留"旧步骤 + 新注记"。
- **理由层（notes/）**：机制被推翻时归档旧 Note 并在台账记 D 号；docs/ 不叠新旧依据。
- **不追加变更史**：文档写的是**现在时**，不是变更日志。历史归 git 与 Note。

## 新文档

先定位层次 → 定该层详略上限 → 定教程/参考 → 写 → 放进对应 tier；**顶层门/宪法**才在 [index.md](./index.md) 书架登记，tier 内文档由目录承载（树就是 inventory）。
**别建集中清单**（第二清单必漂，D28/D34 同款教义）：枚举型事实的家 = 实现自己。

## 负知识（本仓明确不借的）

| 不借 | 为什么 |
|---|---|
| 按时间分目录（"初始化"一类） | 必然长出"烂尾层"：要么始终为真（那是合同，按主题归位），要么已失真（那是历史，归 `notes/` 或 git）。见 [index.md §书架](./index.md) |
| 集中 `INDEX.md` | 违反 DSH no-index 教义（"the lifecycle/class tree **is** the working inventory"）；D34 已据此退役一份。台账只做**路由** |
| 在文档里复述枚举型清单 | 实测六份清单同一种病（D28）：家 = 实现自己，文档留分层原则 + 指针 |
| 用行数当完成门槛 | D26：文件/行数**仅观察**；完成门槛是"该面最小真检查通过"（D15） |
