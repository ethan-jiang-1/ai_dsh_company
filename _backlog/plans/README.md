## 卡片模板

文件名 = `YYYY-MM-DD-<slug>.md`（例：2026-09-28 立的卡 = `2026-09-28-<slug>.md`）：

```markdown
# 推敲：<标题>

> 状态：推敲中｜毕业门判断 = <当前倾向：待定/该做/待触发/倾向放弃/…>｜下一步 = <动作或触发>

## 背景 / 触发
为什么推敲这个：问题、观察、出处（会话/Note/走查）。

## 已知与未决
已核实的事实（带出处）；四问各自的开放点（该不该 / 何时 / 次序 / 放弃）。

## 候选与取舍
候选方向 × 各自代价；为什么 X 不是 Y（备选只记录、不编造）。

## 毕业门
四门各自的满足条件；缺什么证据才能判。
```

**调研类卡**（原 research 层功能，D31 并入）在「已知与未决」里补两字段：
**待答问题 / 待跑实验**清单 + **喂给谁**（结论将喂给哪张卡或哪个决定）。
