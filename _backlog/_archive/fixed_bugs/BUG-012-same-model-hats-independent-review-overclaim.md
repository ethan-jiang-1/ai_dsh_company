# BUG-012：一个模型戴五顶帽子——「异人复核」独立性有限且全程未声明

> 严重级别：P2（次要）｜发现：2026-10-11（V4 复盘协作审计）｜状态：活跃
> **修复（2026-10-11）**：模板侧两条声明栏位（5 份带「AI 使用声明」的模板各加「复核独立性层级」与「边际宽度」）+ `tests/company/templates.spec.ts` keyless 断言守。行为面留作观察触发器：下一份带复核的 final 若仍未出现分层声明/边际标注，新开卡引用本卡（V4 final 全篇无此二者，是本卡的原始反例）。

## 症状（实测）

- V4 五个角色（CEO lead + vp-eng/vp-sales/coo/cfo）是**同一个模型**、四个成员全部 **fork 自同一
  CEO 会话**（派工书原话「你已有前三轮的全部上下文（fork 自 CEO 会话）」）。
- final 的机制留痕写「**异人复核有牙齿**」，但复核的独立性是分层的，声明没有分层：
  - **机械全量重算**（T6 的 244/244 逐格、自校验两条式）——规则确定性 ⇒ 独立性**成立**；
  - **判断类订正**（T6 裁 L34④ 按 fail-closed 计 ✗、T7 改判"读②"身份为混合对照）——与被复核方
    同模同源，共享先验与盲区，独立性**有限**；
- `drafts/vp-eng-review.md` 全文 grep「同模/同一模型/局限/相关偏差」**零命中**——复核稿与 final
  都没有披露这层局限。
- 另一条同源脆弱性未披露：「判据修正单独不够」这条因果腿的边际 = 5.74% vs 5.00% = **0.74pp
  ≈ 1.8 格**——恰好一格两读点（如 L34④ 那种）翻面，结论就翻。final 未标边际宽度。

## 为什么是问题

不是造假——数字全对、订正反向自损（0/244→1/244 更差仍报）、T3 的 R2 被 T7 推翻后作废留档，
这些都可信。问题是**声明强度超过证据强度**：「异人」一词暗示独立人格/独立视角，实际是同模
异线程；对机械重算成立、对判断复核不成立，混在一个词里报。

## 修法方向（候选，未拍板）

- 措辞分级：final/复核稿把「机械全量重算（确定性，独立性成立）」与「判断类复核（同模异线程，
  独立性有限）」分开声明；
- 关键因果结论旁标边际宽度（"差 X 格翻面"），让读者自己掂量；
- 需要真异人时（高危裁定）：引入人或异模型做抽样复核——本仓 `checks/smoke/preset-smoke.mjs`
  换档即是一例先例。

## 用户补充裁定（2026-10-11）

「不同的角色出来，因为它的上下文不一样，它必须是用 Agent 的形式在跑，所以它存在专业性，而不是
CEO 把所有的事都做了」⇒ 两个后果：

- **分开的 Agent 上下文是专业性的物质基础**，也是一层**真实的上下文级独立性**（同模但异上下文、
  异检索路径）——分层声明里这层可以**正当地报**（"上下文独立复核"），但仍不得报成"异人"；
  已随同日扩进手册「协作规矩·对账回合 + 专业域尊重」。
- **CEO 不代劳角色活**：一个上下文扮演所有角色 = 专业性归零——这是 spawn 成员这个动作本身的
  存在理由，写进同条。

## 反证路径

若后续跑法在 final/复核稿中出现分层独立性声明与边际标注，本卡症状收敛；机械重算部分无需改动。

## 现状核实（2026-10-11 按 requirements-synthesis 整理）

- **规则层已落**：手册 `company-workspace/AGENTS.md:104`「复核独立性分层声明」——机械全量重算（确定性 ⇒
  独立性成立）与判断类复核（同模异线程 ⇒ 独立性有限）分开写；关键因果结论旁标**边际宽度**。
  用户同日补充裁定（本卡节）：分开的 Agent 上下文是**真实的一层上下文级独立性**，可正当报为
  "上下文独立复核"，但**不得报成"异人"**。
- **反例在案**：V4 `final.md` 全篇 grep **没有**"独立性"或"边际"字样（`grep -n "独立性\|边际" final.md` 无命中）
  ⇒ 该场既没分层声明，也没标边际宽度。
- **正例为零**：规则落地后还没有一场带复核的 final。
- 候选"需要真异人时引入人或异模型抽样"仍未落（本仓 `checks/smoke/preset-smoke.mjs` 换档是现成先例）。

## 方案比较（2026-10-11 整理）

| 方案 | 内容 | 成本 | 风险 / 边界 | 证据面 |
|---|---|---|---|---|
| A 只等下一份 final 验证 | 下一份带复核的 final 检查是否出现分层声明 + 边际标注 | 0 | 可能很久没有下一份 | final/复核稿文本 |
| B A + 模板栏位强制 | final/复核稿模板加"独立性分层"与"边际宽度"两栏 | 模板改两行 + keyless 断言 | 栏位可能被填成套话；边际宽度不是每份都算得出（无因果结论时该留空并写明） | `company-workspace/templates/` + `tests/company/deliverables.spec.ts` |
| C 高危裁定引异模型抽样复核 | 需要真异人时换模型/换人抽核 | 需外部模型或人；一次性成本高 | 只在"高危裁定"触发，日常不适用；且要定什么叫高危 | 新机制（需授权） |

**建议：B**（A 兜不住——栏位不加，下一份 final 大概率照旧不写；这正是 V4 的实况）。C 留作高危场景的
按需选项，不进常规流程。
