## 方案与取舍

**例外边界（未决 1）。** 用户原话：「偏 2，除非这个 bug 确实很严重，更改了我们某些东西，变了方向之类的」。建议操作化：**P0，或修复触碰以下任一项——章程/常设指令、docs 合同、company-pack 公开行为、已记录决定——不自授权，需用户明确指示和/或走问题 RFC；P1/P2 修复型在修复就绪处自授权。** 确认或改判。

**状态生命周期（未决 2）。** 证据基座 = 源仓生命周期研究（平台三台状态机读自同钉 vendor + 22 张归档卡观察），推荐如下：

*分工（一处事实一个家）：* frontmatter `status` = **当前阶段的唯一家**（一值，只经下述带守卫的翻转）；状态行 = **镜像 + 历史**（裁定追加、离场补「前状态」——本仓归档现行实践）；目录 = 粗位置。门禁活状态类修订为做行↔frontmatter 镜像互查——既有类的加强，不是被延后的验收族。

*状态行增「毕业：」字段，封闭头：* `未定｜做｜以后做｜不做｜消化`（消化 = 关闭表「结论已在别处」），后接自由散文——映射源卡四门，逼门早命名。它保持是倾向不是状态；frontmatter 仍是状态的唯一家。

*问题轨——四值保留，翻转法成表：*

| 从 | 守卫 | 到 | 谁 | 记录 |
|---|---|---|---|---|
| （立卡） | 分诊后——卡只在路由后存在 | 推敲中 | agent | 立卡时 frontmatter |
| 推敲中 | 下一步是用户选择 | 等人拍板 | agent | 「下一步」点名确切问题；仅用户可判时 🔒 |
| 等人拍板 | 用户明确答复 | 推敲中，或离场 | 仅用户 | 状态行追加 |
| 推敲中 | 判断落地＋申请已提交 | 已结（归档同改） | agent | 裁定＋落点指针＋git mv |
| 任意活跃值 | 用户叫停、无结论 | 叫停（归档） | 仅用户 | git mv |
| 叫停 | 用户明确重启决定 | 推敲中 | 仅用户 | 状态行追加 |
| 已结 | 永不重开——复发是新卡引用旧卡 | — | — | 写回律 |

*缺陷轨——「活跃」改名「调查中」；新增 修复就绪／修复已落地／等人拍板：*

| 从 | 守卫 | 到 | 谁 | 记录 |
|---|---|---|---|---|
| （立卡） | 分诊后 | 调查中 | agent | frontmatter |
| 调查中 | 根因有证据确认＋修法选定＋`## 已修判定` 写好；修复为 P1/P2 修复型 | 修复就绪 | agent | 翻转即门票**且**授权（裁定 2） |
| 调查中 | 同就绪，但 P0 或触碰章程/常设指令/docs 合同/pack 公开行为/已记录决定 | 等人拍板 | agent | 通道问题本身 |
| 修复就绪 | 修复已落树 | 修复已落地 | agent | 状态行追加 |
| 修复已落地 | 已修判定满足、证据记录 | 已修（归档同改） | agent | 裁定追加＋git mv |
| 调查中/修复就绪/修复已落地 | 下一步是用户选择 | 等人拍板 | agent | 仅用户可判时 🔒 |
| 等人拍板 | 用户明确答复 | 等待前状态，或离场 | 仅用户 | 状态行追加 |
| 修复就绪/修复已落地 | 根因或修法被证伪——验收失败或新证据 | 调查中（回翻） | agent | 撤回留卡 |

| 待修 | 用户明确重启 | 调查中 | 仅用户 | 状态行追加 |
| 已修 | 永不重开——回归/复发是新卡引用旧卡 | — | — | 写回律 |

*共享翻转律：* **沉默不翻转**（平台 owner-gated 先例：goal pause/resume 须顶层人类请求）；**每次翻转是带守卫与记录的动作**；**出口值只在归档同改翻转**（jobs 终集先例）；`可关闭：是` = 出场守卫旗，随迁档落地（本仓现行法）。

*为什么 修复就绪/修复已落地 值得占位：* 修复就绪一次翻转承载门票与授权（裁定 2＋缺口 4）；修复已落地 = 「实施不是验收」的显形——源仓 BUG-001 占过这个形状而无词可名，等人拍板命名另一半。新增值命名观察到的形状，不发明形状。

**门禁诚实（区别于裁定 1）：** 新值要求修订本仓活状态门禁——`tools/lib/backlog-liveness.mjs` 的 statuses 表与检查（新枚举、调查中改名、行↔frontmatter 镜像互查、毕业封闭头），反证在 `tests/harness/backlog-liveness.spec.ts`——既有类的修订，不新增检查族；被延后的是验收在场**新族**（按状态必备节），记承压候选。门禁改动按 gate-change-definition 技能：红→还原→绿留证。
