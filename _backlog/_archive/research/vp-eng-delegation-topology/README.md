# VP-Eng 复杂任务的委派拓扑：team / 命名专家 / subagent / workflow 怎么组合

> 问题：VP-Eng 接到「复杂」研发包（多产物、多轮、跨学科、要独立评审）时，该用哪条/哪几条委派通道组合？
> 现有合同只有四档文案（自己做 / 一次性 worker / 命名专家 / 持久小队），没有「复杂」的可操作定义，
> 也没有把 `workflow` 编排纳入比较；`workflow` 子代理**不能带 `agentPreset`**（vendor capability），
> 所以它和 SA/SQA 的独立人格不是同一类东西——这条边界要先钉死再谈组合。
