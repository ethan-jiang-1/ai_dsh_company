# 加工环路的入口与事实检查点：fresh agent 走查与门禁对账

> 问题：从 backlog 到 notes 到实现，环路是否让一个 fresh agent 能合法开工、问对问题、交出可执行证据？
> 消费者：用户 2026-11-13 点名（承「我们是不是做对了就会更好」的追问）；落地卡 = [2026-11-13 加工环路的入口与事实检查点](../../settled_issues/2026-11-13-workflow-entry-and-fact-checkpoint.md)。

> 归档：2026-11-13
> 结论：环路的**交付纪律是 A**（授权、备选、红绿、证据、门禁、归档），但四层有缺口——入口（backlog 不是任务源，`待落地` 看起来却像）、一致性（6 处文档自相矛盾）、发现（事实/载体/轴问得太晚）、验收（门禁只查形状，不查是否可执行）。修法按 P0 入口/一致性 → P1 事实检查点 → P2 可执行验收，不一次全上。
