# _backlog · 把问题想清楚

这里记录尚未确定的问题，收集依据，形成结论，再交接或关闭。做什么由用户本轮请求决定；没有点名，不从卡片清单里自行开工。

**backlog 和 notes 是前后两段。** backlog 负责问题、依据、结论和交接材料；[notes](../notes/README.md) 接收申请后决定是否形成 Note、以什么方式处理。不是每张 issue 都成为 Note。申请已提交、去向已记录后，卡可以按关闭条件结束，不等待下游实施或验收。

## 一件事怎么走

1. **记录问题。** 先找已有的 [问题卡](issues/README.md)，没有合适的再新建。写清触发、期望结果、怎么算完成、目前不知道什么。已经确认是缺陷但这次不修的，记在 [缺陷卡](bugs/README.md)；当场修掉的不建卡。
2. **弄清问题。** 缺事实就查资料、读代码或试原型；缺人的选择就说明依据、建议和要确认的问题。短结论回卡片，长依据进 [调研](research/README.md)。按当前缺口查 [方法导航](methods/README.md)，不必跑完整套。
3. **形成结论。** 回答做不做、什么时候做、先做什么、哪些不做。决定做的先写清 [验收标准](methods/validation-design.md)；延后或不做的，写清条件或理由。
4. **申请下游处理并关闭。** 完整申请留在卡上，默认在本轮回复中附卡片链接向用户提出；用户指定接收会话或去处时按指定去处提交。记录日期、接收方和申请内容。[notes 入口](../notes/README.md) 是接收规则，不是收件箱；详见 [交接说明](methods/issue-to-note.md)。不需要后续处理的，留下结论或已有决定的引用。

卡上的状态、方案、建议和交接都不授予实施权限。已由用户授权的工作按原授权继续，不重复请求批准；任务与实施入口见 [开发环 §0.5/§1](../docs/guides/dev-loop.md)。

## 关闭条件

问题已有明确结论，所需确认已得到，需要的下游申请已提交并记录去向，才可关闭。已有结论足以回答的，留下引用即可。按结论检查：

| 结论 | 关闭前留下什么 |
|---|---|
| 做 | 问题、结果、范围与排除项、方案、实际比较过的选择及理由、可执行验收标准，以及申请去向 |
| 以后做 | 理由、什么时候再看、到时观察什么；需下游保留或处理的提交申请。条件到场新开卡引用旧卡 |
| 不做 | 原因与适用范围；需下游保留或处理的提交申请 |
| 结论已在别处 | 指向已有决定或当前合同，说明它回答了什么问题 |

有结论的卡用 `git mv` 进 [已关闭问题](_archive/settled_issues/README.md)，保留文件名和讨论正文，frontmatter 的 `status` 改为 `已结`，状态行补结论与去向，修相对链接并更新两边清单。以后出现新问题，新开卡引用旧卡。

用户明确叫停、尚无结论的，进 [叫停问题](_archive/suspended_issues/README.md)，`status` 改为 `叫停`；重启须用户明确的新决定。事实或答复尚缺的留活跃区，写清缺口与下一步；“决定延后”不是“问题尚未解决”。

旧卡若已经承担实现后的终验，保留其原有未完成要求到验收完成，分别写清技术缺口与用户待确认项。这不是新卡等待下游实施才关闭的理由；“已实现”也不等于“已验收”。

缺陷按 [缺陷规则](bugs/README.md) 处理：修好进 [已修缺陷](_archive/fixed_bugs/README.md)，查明未修进 [待修缺陷](_archive/suspended_bugs/README.md)。研究在最后一张使用它的活卡离开时随迁 [研究归档](_archive/research/README.md)。

## 文件与维护

问题与研究文件用 `YYYY-MM-DD-<slug>.md`，缺陷用 `BUG-<NNN>-<slug>.md`。新问题/缺陷第一项 frontmatter 为 `status`，新研究第一项为 `topic`，具体模板见各目录 README；历史归档不批量回填字段。

清单与目录保持一致，机械形状由 `pnpm verify` 检查；检查通过不证明问题结论正确或方法有效。章程只写制度，现值和条目进各目录清单。状态行带 🔒 的卡仅用户可判定触发，agent 只报告与建议。

本制度整体借自 `ai_dsh_assitant/_backlog` 工作树；取舍、适配与验证见 [落地 Note](../notes/implemented/2026-10-09-backlog-issue-lifecycle.md)。[退役历史池](_archive/legacy/README.md) 保持历史性质，不收新件，也不是任务源。
