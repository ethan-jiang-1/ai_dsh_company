# UX 打磨（驾驶舱与 demo 观感）——已消化，吸收进「demo 可视表达」

状态：已消化（2026-09-23 毕业；条目去向见文末）
类型：feature（原队列序 2）

## 问题

R5b 用户验收口径（原话进 R5b Note）：**「DEMO 水平是够了」**——demo 功能面达标，
交互与观感的打磨预期留后续。该预期此前散在收尾叙事里，未落成条目（本次按队列规则显性化）。

## 提案（骨架；该条目开工时以 Plan Mode 细化钉死验收）

- 驾驶舱/在场板的交互细节：行点击动线、状态文案的可读性、面板刷新节奏的观感；
- demo 分镜（ui-demo §3）的观感顺滑度：以"不讲解能看懂"为轴重放一遍现有分镜，收集打磨点；
- 产出 = 打磨清单按条目逐项落地（每项可独立验收）。

## Alternatives（输掉的方案留尸）

- 不做（保持 demo 现状）：与用户已表达的打磨预期冲突——否决。
- 大改 UI 皮肤 v2（重新分镜）：超出"打磨"语义且无用户证据——否决，留待明确需求。

## 验收（开工前钉死为可机核/可观察）

以一场完整 demo 走查为判据：走查中零卡点、零"需要讲解"的瞬间；走查产出的打磨点
逐条销账（修 / 转搁置池 / 明确不做，各有归宿）。
