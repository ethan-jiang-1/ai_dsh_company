# 2026-09-25 · UX 实验轮：坐进驾驶舱，把"人被拉进来"的感受提早摸出来

状态：已交付（2026-09-26：两场真盘动议跑完 + 四类拉人点全部命中且人侧有真实回应 + 两只真虫修复 +
三档分拣完成；实况见文末，含一条 RFC 未预见、由日志补出的发现）

## 问题

人机合一的机制链路已全通（B2 12/12：审批/问询/补料/缺口回流机器上都能跑），但**体验从未被感受过**。
要的是"提早感觉出来"：CEO 做事 → CFO/COO/VP 互动过程中需要人时，**人这一侧到底经历什么**——
打断的时机对不对、给的上下文够不够、在哪儿回应顺不顺手、一次被拉进来烦不烦。这些只有真人坐进
驾驶舱跑真动议才能暴露；且搁置池里 B3/B4（client 增强）的复活条件恰恰是"实验发现真需要"。

## 实验设计（一场复合动议 × 四类拉人点全覆盖）

动议「大客户 X 年度维护合同续约评估」刻意设计成四类人机接口全部命中：① 要审批（阻塞，双签线）；
② 规矩缺口（阻塞裁决，礼品无规矩）；③ 要资料（非阻塞，竞品报价单）；④ 要建议（非阻塞，市场直觉）。
人这一侧的体验流 = 注意力中心聚合等人条目 → 审批面板（官方 ui-approval）→ 问询卡（选项 + Enter）→
会话内补料/建议 → 轮末文件变更审阅卡 + present 预览。跑法与素材预置见文末实况。

## 输掉的方案

- **先做 B3/B4 client 增强再实验**：没有体感证据就做显示增强 = 又凭空猜 UX（阶段 0 的教训）；
  输给"先感受、证据驱动复活"。**本轮回执**：两场体验中人未抱怨缺这两样 ⇒ 维持搁置。
- **排练场假动议**：假盘感觉不出来；输给真盘真动议（评估类动议无对外副作用，deliverables 三态机器盯）。
- **我代替人跑**：实验对象就是"人被拉进来的体验"，我代跑 = 没有实验对象；用户必须在场。

## 验收

- 一场动议跑完，四类拉人点全部真实命中且人侧各有一次真实回应（日志 + 截图为证）；
- 用户体感笔记落 `notes/research/`（每条：哪类接口 / 时机 / 上下文 / 回应位置 / 烦不烦 + 一句改进）；
- 复盘三档各有产出（小修当场绿 / 搁置池复活裁决有据 / 新提案落 proposed 或明确无）；verify/test 保持绿。

**验收结果**：全部满足，且判据比原设计更强——两场共 2 次审批交互中的 1 次真人点击 + 2 轮问询共
6 条人侧回应（3 条选项 + 3 条自由文本）全部在会话日志里可逐条回溯（坐标见下表）。体感笔记一度
归档为 `notes/research/2026-09-25-ux-experiment-notes.md`，本轮按 research 层生命周期**结论并入本 Note
后删除**（末次 blob `310227d`，全文归 git）；原笔记"未逐一确认"的判读经日志复核**已修正**（见下节）。

## 风险（跑前登记）

- 真动议成本 ≈ $2–5 + 用户在场 15–30 分钟；模型方差可能漏触发某个拉人点（预案 = 缺哪个补跑哪个
  单点，不整场重跑）。**实况**：四类全命中，未用上补跑预案；两场实际占用 ≈ 2 小时 10 分（含修复与走查）。
- 动议若跑偏（成员没按规矩走）：偏航本身也是实验数据（如实记），不中途救场。
- **未登记但成真的风险**：追问疲劳——原设计只防"漏触发"，没防"问得太多"。见「最值钱的一条」。

1. **场一「规矩缺口」不是"人裁了 ≤$200"**：人只确认"无规矩"+ 授权转授，**上限 ≤$200 是 CFO 建议、

2. **场二「双签又见」不成立**：场二**没有审批交互**——CFO 判三条否因各自独立成立，**未提交**
   `request_signoff`（不制造一次无效双签；处置见 `deliverables/revenue-plan-2027/final.md:132`）。
   8.8 折不批是 CFO 的判定，不是人点的。

### 最值钱的一条：追问疲劳（原 RFC 未预见，靠日志补出）

场一把**三件不同性质的事**（补料 / 直觉 / 规矩缺口）压进**一次** `ask_user_question`（4 问同屏），
第一轮人选了「现在给 / 我直接说 / 我裁」之后，CEO **紧接着第二次追问同一批内容**，人的第三条自由文本是
**「哎哟，别烦我了，你随便找人吧」**。这是"一次被拉进来烦不烦"的**首个硬证据**，也说明原笔记把
"规矩缺口命中 ✓"读成了成功——**机制上通了，体验上是失败的**：人答"我裁"是配合，被追问后转成
"别烦我"。同时它解释了为什么补料/建议两条最后是负向答复（"暂时没有"/"判断不出来"）：**不是没料，
是问的方式让人不想给**。

候选处置（待人裁，已挂 ROADMAP §磨清单）：① 文案/规矩层小修——手册「人机接口」节 + 问询相关 skill
加**问询节流纪律**（一次只问一件；非阻塞项不与阻塞项同屏；同一批内容不许串行追问，缺料就按缺料出稿）；
② 若判为机制面 → 新提案（注意力/问询面的批量与节流）。**未擅自改手册**：改规矩 = 立法，归人。

**方法论实证**：用户坐进驾驶舱约十分钟，抓到两只门禁全盲的真虫；"提早感受"的价值不用再论证。
