# implemented/ —— 当前决定的 rationale owner

> 本目录回答：**现在为什么这样做**。不是档案、不是日记、不是提案停车场。
> 分类与生命周期唯一家 = [../README.md](../README.md)；本文件只写这一层的宪章，不记内容清单
> （文件一直在变，清单 = 目录本身）。

## 收什么

- 已随某次变更落地的决定：**决定 + 输掉的方案 + 后果/边界 + 真跑过的验证**。
- 仍可能阻止重开的否决：为什么没选另一条路。
- 事实落点（路径/符号/默认值）随改动就地更新；**决定正文冻结**。

## 不收什么

- 收据：轮次/会话收尾、演练场次、E2E 首跑、批次流水、状态快照 → [../archived/receipts/](../archived/receipts/)
  （叙事性收据；机器证据优先 `snapshots/` 或部署仓）。
- 未实施的提案 → [../proposed/](../proposed/)；未成熟思考 → `_backlog/issues/`。
- 已被完整吸收、只剩否决的旧决定 → [../archived/](../archived/) 顶层。
- 与现行合同相反的旧文：改现行 owner，或加“被…取代”指针并归档；**不要两篇并排**。

## 读法

- 先看状态行与标题，再找「决定 / 输掉的方案 / 后果 / 验证」。
- `docs/` 是 now，本目录是 why；冲突要修，不能默认旧文对。
- 取代必须双向（[../README.md §五](../README.md)）；`notes-supersession` 门禁查回链。
