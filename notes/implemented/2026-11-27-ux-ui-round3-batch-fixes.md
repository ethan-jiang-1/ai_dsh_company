## 输掉的方案

- **只靠隐藏或保留空「开始」Guide 页签来迎合旧版 `cdp-probe`**：保留不带 `replaceTab: true` 的 `openTab` 会持续留下空开始页（违背上游 `GuideBody` / `BUG-403` 契约）；正路是在插件侧传 `{ replaceTab: true }`，并在探针侧适配点击上游官方 `[data-dockkit-add-tab]`。
- **只在 UI 渲染期包一层 `error.message` 翻译，而不改底层错误函数签名**：会破坏既有多语言断言及未来更多直接调用路径；在 `company-root`/`write-gate`/`runtime-guard`/`cultivation-context`/`readContext` 引入默认 `'zh'` 的可选语言参数和单分支选择器，既 100% 兼容既有中文调用与单测，又避免覆盖率棘轮分支膨胀。
- **把 `useSyncExternalStore` 引入 `cultivation/` 或 `startup/` 目录**：违反 `client-css` 对组件 hooks 约束，继续保持局部 `useState` + `useEffect` 显式订阅。
