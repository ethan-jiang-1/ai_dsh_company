# D5 提分：真页面从"冒烟"升级为"有金样的回归网"

> 上游 = [六维提分卡](../../_backlog/_archive/settled_issues/2026-10-27-six-dim-raise.md) 批三。

## 决定

1. **隔离场景**：`ui-scene-smoke --isolated` 用 `tools/standalone.mjs --provision-only` 建临时 home/公司盘
   （实测 **3.8s**），再起 web → cdp-probe。dev 盘数据不再影响断言；`--keep` 保留现场。
2. **逐页签文本捕获**：`cdp-probe --texts` 把每个页签面板的可见文本放进 `verdict.tabTexts`；
   `--json-out <path>` 把最终 verdict 落文件（跨进程消费；通用能力，不只给金样）。修了一处落点 bug：
   第一版把写文件块插到了"启动失败"的早退分支，导致最终 verdict 不落盘——已移到末尾。
3. **金样档**：`ui-scene-smoke --isolated --golden` 与 `snapshots/visual/company-shell/ui.golden.json`
   比对（归一化 = 去零宽、折叠空白、trim；不掩码数字——隔离空壳里计数与时间都是确定的）；
   差异打印"页签 + 首差字符前后文"；`--refresh-golden` 是唯一更新入口。
4. **静态门禁 `ui-golden-freshness`（第 50 门）**：金样 schema/scene、目录 == 页签注册面解析结果、
   每页签文本非空、无多余页签；金样被删即红。
5. **场景登记**：`snapshots/visual/company-shell/`（既有 `visual` kind，不新造 kind），
   `snapshots/README` 登记来源性质（合成、无部署数据）与"唯一更新入口"。

## 输掉的方案

- **把金样放 `snapshots/ui/`**：`canonicalSnapshotScenes` 把 `snapshots/` 的直接子目录当 kind，
  未知目录按"遗留平铺场景"抛错（实跑红：`Legacy flat snapshot scenes remain: ui`）——
  复用既有 `visual` kind 而不是新增 kind。
- **在 dev home 上做金样**：台账/成品/培养读公司盘活数据，文本随部署漂移；隔离盘才可复现。
- **做完整 `replay --ui` 合成回放场景**：要真模型录制 + aria 金样，成本与维护面都高；
  本轮先覆盖"外壳 + 空态"的可见文本，会话内数据面仍由 keyless 渲染 spec 覆盖。**这是有意的范围**。
- **用无会话 dev 实例的文本**：同一份文本里"目录不可达/不可读"来自没有会话的降级路径，
  不是真实用户视图——已在 Note 与 README 里写明金样只证明外壳，不冒充数据面。

## 后果

- UI 改动第一次有了"内容变了会红"的回归网；`replay-ui-freshness` 仍 SKIP（没有回放金样），
  但 UI 金样由新门禁守。
- 真页面车道一条命令可复现：`node checks/smoke/ui-scene-smoke.mjs --isolated --golden`（~30–40s keyless）。
- 金样 2.7KB / 9 页签；`snapshots` 总量仍在 0.1M/2M。

## 同批测试卫生（非金样）

- **夹具出处**：`tests/fixtures/README.md` 逐件登记来源/生成方式/用途；`fixture-provenance.spec.ts`
  机械校验"盘上每个顶层夹具都有行 + 硬规矩在场"。4 个专属夹具全部标注 authored/derived。
- **4 个单 `it` 巨测（tab-registration / composition / role-mark-fixture / session-adapters）明确不作**：
  它们是**有序生命周期叙事**（先声明类型 → 等槽 → 装 keyed 渲染器 → 折叠/重装/卸载），拆成多个 it
  要重复整套 setup 且容易改变时序；失败粒度收益低于回归风险。等真出现"改一处要跑全文件"的痛点再拆。
