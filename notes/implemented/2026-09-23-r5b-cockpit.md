  一轮 → v1 动态流 = 快照差分，消息级进搁置池。host 投影通道已核实存在

  是复活时的现成路径。
- **`paceMs` 修 queued 差异**：vendor 明说 "correctness must never depend on it"——性能旋钮不当
  正确性用。

## r2 presence 判据档的理由（写给下一轮）

r2 录制是 **2026-09-22 的内容快照**；CEO persona / 公司手册（R4 三态节）/ R3 委托工具此后演进，
重放忠实用**当前**组合 ⇒ 归一化全量与 sidecar 的逐字节零 diff 必然红（那正是重放灵敏度的证据，
不是缺陷）。故 r2 用 `replayJudges: presence`：member/task 集合等价 + 在场板同形；组合漂移检测
归 r3-delegation full 档（R5a 重录、与当前同代）。另两条实证：① `delivered` 事件的 targetId /
messageId token 序受投递确认竞态影响（不在读模型数据路径）；② 收割排序必须按 createdAt
（目录序在多 child 下全错位——本次修的真实 bug）。
