# 2026-09-22 · R2 内容片:全员五角色上线(含 CFO 增设)+ 编制唯一事实家

## 决定(用户拍板 + 代理起草)

1. **CFO 增设为第五角色**(用户提议):50 人高科技公司必须有财务职能;财务 agent 案
   (对账 / SoD / 影子账闸门)给了 CFO 完整的专业戏份。显示名 `wochen CFO`,id `cfo`。
2. **公司编制 = 50 人,细到岗位,唯一事实家 = `company-workspace/kb/org.md`**(用户定案:
   "编制你要统一""假定 50 人""管辖职位尽量分细")。五条线:CEO 与公司职能 3 / 财务(CFO) 4 /
   销售与市场 7 / 产品研发 18 / 交付与客户成功 18。各角色 CHARTER 只留本条线事实并引用
   org.md,禁止另写总数(D10「一处事实一个家」的公司盘版本)。
3. **每角色至少 1 个自己的工作流 skill**(用户要求"每个人都有 workflow 自己的,至少一个,
   今后会多个"):CEO = `chairing-staff-meeting`(既有);VP-Eng `eng-workflow` /
   VP-Sales `sales-workflow` / COO `ops-workflow` / CFO `cfo-workflow`(均为端到端 SOP,
   末步含任务板回执与 journal)。后续按 `<role>-workflow-<主题>` 追加 2 号、3 号。
4. **专业打法取自行业标准**(用户授权网络检索):销售 = MEDDIC 六问资格 + 双向估算;
   交付/运营 = SOW + 里程碑验收(UAT)+ RACI;财务 = SoD、留痕字段、四流一致、AI 产出
   不得入账(影子账闸门,直接继承财务 agent 案口径)。来源:meddicc.com 一手资料等,
   见对话记录;要点已内化进 skills,不依赖原文。
5. 派生事实随编制重定:并行交付项目上限 2 → **8**(PMO 3 人);报价毛利底线 **30%**,
   折扣 <9 折或毛利 <30% = **CFO+CEO 双签**;固定支出审批线 $50 → **$500/月**(CFO 会签
   + CEO 签);云基础设施 **$2,000/月**(SRE 管控);AI 试点项目 API 仍为**每案 $200/月硬顶**
   (各案交付物口径不变,历史兼容)。
