# 2026-09-22 · R1 关轮：两人公司跑通第一条动议（+ 两道上线前防线）

## 决定

1. **R1 验收达成**（外部可观察）：CEO 会话收动议 → 澄清 → 建任务板任务 → `spawn_teammate(vp-eng)`
   → VP 出稿并自生 research worker → CEO 合稿 `present` → `deliverables/` 两份文件 + 两个
   journal。合稿守住 persona 三条收口原则（不代笔"未改一字"、保留分歧、引用 veto 规则）。
2. **preset 工具行必须连 config 一起抄**（根因）：`tool-fs-search.sampleOverCapGlobResults`、
   `tool-todo.allowParallelInProgress` 是 schema 必填项；只抄行名 → Loader 校验失败 →
   **整个 preset 挂载失败** → UI 静默（"新建会话没反应"）。
3. **两道上线前防线**（回应"上线后才发现"）：
   - **防线一（快，进 `pnpm test`）**：检查已知必填 config 字段是否随行给出（第 8 条）。
   - **防线二（真，上线前必跑）**：`scripts/preset-smoke.mjs` —— boot 真 web profile，
     `agentPresets/list` 断言四角色零 broken，再**逐个 `session/create` 挂一次**（这一步才触发
     config 校验）。keyless、约 20 秒。
   - **反证（DSH 纪律：guard 必须能变红）**：去掉 `tool-fs-search` 的 config → 冒烟精确报
     `preset "ceo" failed to mount: $.sampleOverCapGlobResults missing required value`，其余三个
     preset 仍 PASS；恢复后 ALL PASS。
4. **补上团队 Web 可视面**：pack bundle 增 `ui-agent-team` insert
   （`@deepseek-ai/dsh-experimental-client-ui-agent-team`，官方 `agent-team-web-profile` 的同一条
   行）→ Web GUI 出现 Team 按钮 / 名册 / 实时任务板 / 点进 VP 会话。这是观察任务起止的最简途径；
   当初用直插 host 行时漏了 client 这一半。
5. **`file:` 副本是硬链接（更正旧说法）**：profile 里的 pack 文件与源文件**同 inode**——
   改**已有文件**自动同步（不必 cp）；"要 bump 版本/重装"只针对**新增文件**与**依赖变化**。
6. **首份回归资产**：`snapshots/r1-motion/`（Lead 会话 235 行 + `workspace.expected/` 独立 oracle：
   两份交付物 + 两个 journal）。

## 输掉的方案

- **进程内挂载测试**（import `mountPreset` 直接挂）：需要完整 Cordis scoped ctx 管道，脆且版本敏感；
  真入口冒烟更符合"Test the real entry path"。
- **只靠 roster/dump 检查**：`discoverPresets` 只解析 YAML + 解析包名，`--dump-config` 只打印
  profile 树——两者都**看不到行 config 校验**，正是今天漏掉的那一层。
- **装官方 `agent-team-profile` bundle**：会 disable 全局续驶控制（10 §3 冲突注①）；改用直插行 +
  只补 client 那一行。

## 验证（实际跑过）

- `pnpm test` → **8 条全绿**（含防线一）。
- `pnpm verify` → ALL PASS。
- `node scripts/preset-smoke.mjs --port 3099` → **ALL PASS（4 个 preset 全部可挂载）**；
  注入回归后 1 FAILURE（精确指向 ceo 与缺失字段），恢复后 ALL PASS。

  CEO 工具序列含 `read → skill → ask_user_question → team_task_create → spawn_teammate → wait_agent`。
