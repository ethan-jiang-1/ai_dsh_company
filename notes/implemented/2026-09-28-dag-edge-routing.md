# DAG 边线车道分离——拿走「中段打结」的重合感（已交付）

状态：已交付（2026-09-28 实施同日全验收链通过。源卡
[_backlog/_done/_closed_plans/260928-dag-edge-routing.md](../../_backlog/_done/_closed_plans/260928-dag-edge-routing.md)）

## 问题

依赖图的交叉本身是行布局下限（barycenter 单遍已到下限；前置分居两端的形状至少 2 对交叉，
2026-09-28 试用反馈轮实测）——**排序无解，非 bug**。刺眼点是：多条边在层间带里**共用同一条
走廊**，交叉段彼此重合，收官全绿时读作「一团乱麻」。

## 方案（已落地：车道分离，`dag.ts` 纯函数，零新依赖）

- 同一带（from 层→to 层）内的边按（源 x、目标 x）排序，各占一条 y 通道：
  `lane = y1 + (y2−y1)·(i+1)/(n+1)`；贝塞尔控制点从共用的 `mid` 改为各自 `lane` ⇒
  中段水平段互斥，交叉从「叠着过」变「错层跨越」。
- **单边带 lane = 中点**：渲染与旧版逐像素相同（大多数小图/链不受影响，快照零 churn）。
  跨多层的边自成一组，仍走中点（多带边与同带边的残余重合是已知边界，见下）。

## 输掉的方案

- **metro/orthogonal 全路由 + 布局库**（dagre/elkjs）：效果上限更高，但违背「≤20 节点不引布局库」
  的既有取舍（`dag.ts` 头注）；图真变大时再按采用度门槛另立条目。
- **hover 高亮依赖子图**：静态乱不减少，只是交互补偿；留作磨活候选。
- **不做**：用户点名要修。

## 追加切片（同日第二轮用户反馈：「还是乱的」）

车道分离消了重合，但五条**弧线**以不同高度扫过整条层间带 + 2 个 X 交叉，在 ~730px 小窗里
仍读作一团面条——用户看图裁定还是乱。追加两件事（仍 `dag.ts` 纯函数、零新依赖）：

- **正交走线（V-H-V）**：`M x1 y1 L x1 lane L x2 lane L x2 y2`——垂直下探、水平轨、垂直入靶，
  电路图形态；交叉变成清晰的垂直跨越点。
- **锚点散开**：多入边的靶节点顶边按 `(k+1)/(n+1)` 分锚（末段垂直线不共线）；多出边同款分底边；
  单入单出保持中心锚点（向后兼容）。

验收追加：keyless ×2 新钉（V-H-V 三段对齐 + 同靶锚点不共线）红→绿，共 246/246；夹具档
12 判据 ALL PASS；真板面 DOM 断言（民政场 5 边全部 V-H-V、车道 80–120 互斥）。曲线形态
（贝塞尔）被本切片取代——若将来要回曲线，git 历史在本 Note 前一版。

## 已知边界

- 跨多层的边（如 L0→L2，穿过中间行的带）与该带内的边仍可能视觉重叠——车道互斥只在
  同带内保证；多带边路由（绕行中间节点）留给图规模真正变大时与布局库议题合并推敲。
