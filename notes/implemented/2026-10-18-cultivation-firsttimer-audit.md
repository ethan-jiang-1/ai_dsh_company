# 培养面板「第一人称走查」（模拟）：四观察 → 四修复 + 七条判据自评

状态：已交付（2026-10-18；用户令「你来模拟，你有能力，整个过程你自己都能看到…把你希望的都跑了」）

> 这是**模拟**，不是真人体验：我以维护者身份扮演"第一次用它的人"，真浏览器逐步操作 + **逐张读自己截的图**，
> 记录"看到什么 / 下一步会点什么 / 哪里停住"。它比纯机制判据强（看图说话、能抓文案与布局），
> 但**替代不了真人的困惑度**——那一格仍以 [体验协议卡](../../runtime/human-exits-evidence/cultivation-ux-protocol.md) 为准（模拟结论只用来**先修掉明显缺陷**）。

## 决定（四条 UX 规则，仍现行）

1. 破坏性动作的后果说明必须在确认按钮**之前**读；确认按钮另起一块。
2. 表单字段用常驻标签，不用只靠 placeholder 的隐形标签。
3. 回执文案与用户看到的按钮同名（命令留在括号里给熟手）。
4. 摘要不重复正文已说过的句子；摘要只给结论与下一步。

## 方法（可复现）

```sh
source run/env.sh && node probes/browser-visual/cultivation-ux-walkthrough.mjs --shots
# 每步截图落 runtime/human-exits-evidence/ux-shots/（00 首屏全页 / 01 空态+创作入口 / 02 待办行 /
#   03 采纳后 / 04 拒绝表单 / 05 撤回后果 / 06 创作表单）；再由人（我）逐张读图记录。
```

模拟环境：真 web 实例 + chromium 1440×1000，会话角色 = CEO（公司盘），T1–T6 + T3b **全 PASS**。

## 观察 → 处置（四处，均为真缺陷）

| # | 我在图上看到什么 | 为什么是缺陷 | 处置（同 diff 带判据） |
|---|---|---|---|
| 1 | 待办行里同一句话出现两次：先当摘要显示"做法：…"，下面正文块又从这句开始 | 纯噪音；新人会以为"这两条不一样吗" | 正文就地展开时不再渲染首句摘要（只留出处行）；交互档加断言"首句只出现一次" |
| 2 | 撤回的后果说明**夹在按钮中间**（这条有用 ｜ 没起作用 ｜ 撤回警告 ｜ 确认撤回） | 破坏性动作的警告必须在按钮**之前**读，夹在中间等于没读就被点 | 后果独占一行、确认按钮另起一块；交互档加 DOM 顺序断言（`compareDocumentPosition` = FOLLOWING） |
| 3 | 宿主回执甩命令行词：*"验证后用 verify 回填结果；不灵了用 revoke … 撤回"* | 面板上没有叫 verify/revoke 的控件（按钮叫「这条有用」「撤回…」）⇒ 指引对不上控件 | 回执改人话并与按钮同名（命令留在括号里给熟手）；`tests/company` 断言同步 |
| 4 | 创作表单只有 placeholder：打完字标签就没了，正文栏也没说"证据写什么" | 不熟的人中途会忘哪栏是哪栏；"证据"没有样例 | 两栏改**常驻标签** + 正文栏加一行提示（做法 + 出处坐标）；交互档断言标签在打字后仍在场 |

## 七条 UX 完成定义 · 自评（模拟口径）

| 判据 | 结论 | 依据 |
|---|---|---|
| 1 新人不看说明指出"哪几条是给我的"并说出内容 | ✅ | 首屏「需要我处理」在首屏、行内含期望行为与正文（T1 3 步） |
| 2 不抄 id 完成采纳，并正确回答"何时生效" | ✅ | T2 2 步；「新开的…会话会加载它」在行内（T3 2 步） |
| 3 拒绝不写作文、回执能看到理由 | ✅ | T4 4 步；理由落记录并在「我提交的」显示 |
| 4 失败后知道为什么、下一步去哪 | ✅（机制） | 失败出宿主原话（跨角色/已处理）；模拟未构造失败面，真人档可补 |
| 5 看出哪些方法没验证并回填 | ✅ | 「未验证」标签 + 「这条有用」按钮（T5 2 步） |
| 6 不看说明能自己提交一条并知道去哪 | ✅ | 创作入口在顶部、提交后行内回执 + 记录进「需要我处理」（T0 观察） |
| 7 没有"看到却不知去哪操作"的条目 | ✅ | journal 块标「不用你操作」、「我提交的」标「等对方处理，你无需操作」 |

## 未替代的（如实）

- **真人困惑度**：本记录是单观察者（我）的模拟，无"想了两秒才懂""误解了措辞"这类信号。
- **空态与失败态的真人反应**、窄窗/浮窗形态、多人同时看同一面板的互动——都没覆盖。
- 协议卡（`--protocol`）仍是给人跑的那一页：任务表 + 三个必答问题 + 回执口径。
