# P3 续作：把第四轮明确留待以后做的四项清零

> 上游 = [第四轮归档卡](../../_backlog/_archive/settled_issues/2026-10-28-repo-hygiene-round4.md)；复评 = [报告 §9](../../_backlog/_archive/research/repo-hygiene/2026-10-28-six-dimension-audit-round4.md)。

## 决定与后果

1. **共享测试夹具**：新增 `tests/support/temp-env.ts`（`makeTempDir` / `createTempEnv`），迁移 5 处 mkdtemp/env 样板——`host-composition`、`apply-lifecycle`、`catalog-wiring`、`catalog`、`two-homes`。环境保存/恢复与目录清理只留一处实现；测试失败时不再各自手写 `rmSync`。
2. **Board 余四块**：新增 `client/CultivationBoardSections.tsx`，收「我提交的 / 已采纳 / journal / 赞踩」四块；`CultivationBoard` **311 → 141 行**（单函数从 226 降到约 56 行），余下只有身份条、创作入口、收件箱/分区调用与「怎么养」静态说明。
3. **command handler 六支**：`adopt` / `reject` / `verify` / `archive` / `purge` / `check` 各自成命名函数；`cultivationCommandHandler` **206 → 56 行**，只剩前置与分派。40 条 cultivation spec 全绿。
4. **`cdp-probe --attach`**：
   - `tools/drivers/cdp-driver.mjs` 新增 `attachCdpBrowser`（不改既有 launch 路径）；
   - `cdp-probe --attach <devtools-port> [--attach-url <substring>]` 做**只读快照**：不导航、不关模态、不点页签、不跑 `--ask/--steps`；抓 composer、品牌、错误环、body、截图；
   - 品牌断言在 attach 档不强制（用户页可能不在公司首屏）；`--evidence` 的 `evidenceDir` 返回修复；
   - 端口守卫抽 `tools/lib/cdp-attach.mjs`（纯逻辑）供 driver 与 keyless spec 共用，避免 tests 直接 import driver 违反 layering。

## 输掉的方案

- **把夹具 helper 做成全局 setupFiles**：拒绝。Vitest 全局 setup 会隐式改所有 spec 的 env/目录；显式 `createTempEnv()` 才能让每个用例看见自己拿到什么。
- **Board 四块各开一个文件**：拒绝。四块共享 board 状态且都短；一个 sections 文件足够，避免 4 个新 import 点。
- **command handler 改 dispatch 表**：拒绝。显式 if 分派保留未知子命令的统一兜底文案；等有第二个消费者再收表。
- **attach 复用 launchCdpBrowser 加开关**：拒绝。attach 不启动/不杀 Chrome、不导航，复用会把两套生命周期缠在一起；独立函数更容易守住“只读”。

## 验证（实跑）

- `pnpm test` → **111 files / 980 tests passed**。
- `pnpm verify` → ALL PASS；`pnpm typecheck` → exit 0。
- `ui-scene-smoke --isolated --golden` ×3 → 全绿（9 个页签、错误环零命中）。
- attach 真跑：
  - `--attach 9222` 对 about:blank：`attached=true`、`pageUrl=about:blank`、不崩（exit 1 仅因不是 GUI，符合预期）；
  - 起真 GUI + 带 `--remote-debugging-port=9222` 的 Chrome，`--attach 9222 --attach-url 127.0.0.1 --evidence`：**exit 0**，`composerReady=true`、`errorRingInstalled=true`、`clientErrors=[]`。
- layering：新增 `tests/harness/cdp-attach.spec.ts` 只 import `tools/lib/cdp-attach.mjs`，`layering` 与 `src-layering` 均绿。

## 边界

- attach 需要用户/运维显式以 `--remote-debugging-port` 启动 Chrome；默认浏览器不会开这个口。
- attach 只做快照，不驱动页签/交互；要复现点击仍走自起实例 + `--steps`。
- P3 四项已清零；没有新的“以后做”条目。
