# rejected/ —— 被推翻/过时的研究稿（负知识）

> 本目录只收**结论错且不再被引用**的研究长文，防止复犯。
> 清单 = 目录本身；失效即删。分类与处置的唯一家 = [../README.md](../README.md) §五。

## 语义区分

- 结论错但**仍被引用** → [../archived/](../archived/)（冻结的否决）。
- 结论错且**不再被引用** → 这里。
- 被否决的**方案**（不是研究稿）→ 仍住各 owner Note 的「输掉的方案」节，不进本目录。
- 没有持久结论的收据 → [../archived/receipts/](../archived/receipts/)，不进这里。

## 维护

- 新稿进这里前先问：它还能阻止同一个可信错误吗？不能就别留。
- 引用它的地方失效后，这里也失效——删，历史归 git。
