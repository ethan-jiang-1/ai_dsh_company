# 2026-10-06 · 测试资产收割机制：运行→收割→钉住

状态：proposed（批准：2026-10-06 用户采纳「收割三问 + 资产层投资」框架并令设 ongoing goal 推进；次序 A→B 由本 RFC 拟定；投资判据四问 = 承重/回归史/维护成本/存活于升 pin）

## 问题

「跑的过程中抓 bug」已被验证是本仓资产增长的主通道（回归 283→345 项，BUG-001/002/003 均由真跑收割），但它是**自发**的——依赖某次对话里恰好撞见。另外三个通道几乎零增长：录制回放场景仅 7 个（近期零新增）、语料 1 个、视觉夹具 2 个。跑了就跑了，行为没钉下来。缺的不是新工具（录制/快照/判据 lane 全现成），缺的是**收割自觉的机制化**——让「这次跑要留下什么」和「抓 bug」一样成为默认动作。

## 方案（两条目）

### 条目 A：收割三问进现有合同（机制层，立刻落）

把三问写进三处现有收尾面，零新工具（D13：用现成载体）：

1. **dev-loop §12 收尾动作**加一行收割检查：这次真实运行——①抓到异常没（→BUG 卡+红绿）②行为值得钉吗（判据：「变了我们要不要知道」→录制场景/keyless 断言/视觉夹具）③撞到运行态事实没（→调试阶梯/Note，能机械守卫的升级 probe）。
2. **budget-and-ops demo runbook** 收尾行加同款三问（demo 是最高频的真实运行）。
3. **dev-loop §0.5 长程 goal 节奏**补一句：每条简报带「资产增量」一行（涨没涨可见）。

验收：走查——下一个真实运行/goal 简报里三问与资产增量行在场；md-links 绿；行预算不升（dev-loop 375/395 有余量，budget-and-ops 无预算）。

### 条目 B：录一个当前组合下的新 replay 场景（资产层）

- 用现有录制 lane（replay-smoke `--record` / e2e 驱动，真模型）在排练环境跑一次**标准五角色动议**（形状同 r2，但用当前组合——r2 录制于 2026-09-22，组合已漂移，当前基线本身就是要钉的资产）。
- 场景入 `snapshots/replay/`，snapshot.yml 按[快照规则](../../snapshots/README.md)场景元数据政策声明：**来源性质 + 代码锚**（新场景必须记——run bundle 引用合同字段）。
- 回放资格如实声明：能配出可回放判据就配（presence 档起步），不能就声明不可回放原因（判据档位政策允许）。
- 走查：新场景被 snapshots/README 索引行覆盖 + `pnpm orient --scenario replay/<新场景>` 能算出 run bundle 视图。

## 非目标

- 不做覆盖率指标/中央测试计划/收割调度器（磨清单退役教训，不发明）；不动 evidence 政策与三态判据；不为铺量录制多场景；不钉 vendor 内部实现（只钉本仓合同行为）。

## 输掉的方案（留尸）

- **建收割调度器/清单工具**：磨清单已退役（2026-09-28），中心队列必腐；三问进现有收尾面 = 零新载体。
- **为覆盖率铺测试**：testing.md 立过的否决——测试变多 ≠ 绿有意义。
- **录多用户复杂大场景**：r5b 已覆盖多用户形态；标准动议的**当前基线**才是缺口，成本可控。
- **把运行态事实直接钉成断言**：headless 收尾删目录等属运行态生命周期，keyless 面测不了；它们的家是调试阶梯/Note，能守卫的已守卫（如 parseSessionHead 夹具即源自真实日志形状）。
- **等用户下次手动跑再录**：e2e/录制 lane agent 可自主驱动真模型，等待是不必要的延迟。

## 验收（先行点名怎么测；每条目独立红绿）

- **A**：①走查判据——dev-loop §12 收尾节、budget-and-ops runbook、§0.5 节奏句三处收割面在场且一句话可执行；②md-links 绿 + 行预算不升（dev-loop ≤395）；③负例自查：三问缺任何一处即视为未落地（走查记录进毕业 Note）。
- **B**：①新场景目录 + snapshot.yml 在场且字段齐全（scenario/recordedAt/代码锚/profile/agentPreset/cwd/session/workspace/来源性质）；②snapshots/README 索引覆盖新场景（门禁/走查）；③`pnpm orient --scenario replay/<新场景>` 输出完整 run bundle 视图；④回放资格如实——可回放则 replay-smoke 该场景 PASS，不可回放则场景 README 声明原因；⑤真模型成本：一次标准动议运行（限流旋钮按 budget-and-ops 默认）。
- 每条目一个 commit + push + 简报（带资产增量行——自条目 A 起生效，本包即首个示范）。
