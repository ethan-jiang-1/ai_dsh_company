## 由编制派生的公司事实（各案引用这里，不另立数）

- **并行交付项目上限 = 8 个**（PMO 3 人按 1 PM : 2–3 项目）；超出 = COO veto「接不住」。
- **报价签字线**：项目毛利底线 **30%**（CFO 现行口径）；低于底线或折扣低于 9 折 = **CFO + CEO 双签**。
- **基础设施有专人**：SRE 2 人（属研发条线）；无 DBA（后端兼管）——评审仍须答「谁维护」，具体到人。
- **预算**：云基础设施 **$2,000/月**（SRE 管控）；AI / agent 试点项目 API = **每案 $200/月硬顶**
  （达线自动停，现行各案口径，如 `deliverables/agent-workflow/final.md`）；新增固定支出（订阅 / 外包）
  ≥ **$500/月** = CFO 会签 + CEO 签；超限方案必须带降档预案。
- **客户盘**：现有客户 9 家中型企业（6 家带年费维护合同）——客户画像与定价细节归
  `kb/vp-sales/CHARTER.md`。
- **内部系统**：两个内部服务（Node.js 22 + SQLite）；工具链 = Markdown + git + 每周例会纪要。
