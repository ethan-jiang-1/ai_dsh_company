# 运营核查 · 一页纸（COO 模板）

> 用途：落地核查 / 运营方案 / 预算核查类产出（COO 主用）。结论先行，一页为限。
> 与 `review-note.md`（VP-Eng 技术评审：自建/现成/混合）区分：本模板的三选一是
> **接得住 / 有条件接得住 / 接不住（veto）**，并强制三格齐 —— 谁执行 / 走什么流程 / 花多少钱。
>
> **AI 使用声明**：起草 =（人 / AI 起草：具名）｜具名复核人 =（姓名；复核担责）｜复核日期 = YYYY-MM-DD｜版本 = v_（与稿首署名行同号）
> **复核独立性层级** =（机械全量重算（规则确定性 ⇒ 独立性成立）｜上下文独立复核（同模但异上下文/异检索，独立性有限，**不得报成「异人」**）｜判断类复核（同模异线程，独立性有限））｜**关键结论边际宽度** =（差几格 / 几个百分点翻面；本件无因果结论写「无」）。
> **缺声明不得进 SOW / UAT / 对客材料**；`drafts/` 过程稿不强制，但进 `final` 或对外件必须齐。
> 复核人栏**必须写姓名**；姓名册补名前**不得以岗位名充作姓名** ⇒ 对客件在补名完成前 **fail-closed（不得外发）**（与「未具名 = 不启动」同源）。
