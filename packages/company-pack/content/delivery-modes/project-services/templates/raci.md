# RACI 模板（项目制 / 系统集成）

> 层：交付模式 · 由 COO 主笔；R = 执行，A = 最终负责，C = 咨询，I = 知情。一格只能有一个 A。

| 活动 / 交付物 | COO | VP-Eng | CFO | VP-Sales | 客户 |
|---|---|---|---|---|---|
| SOW 范围 | A/R | C | C | C | C |
| 技术方案 | C | A/R | I | I | I |
| 项目经济性 | C | I | A/R | C | I |
| 定价 / 合同 | C | I | C | A/R | C |
| UAT 验收 | A/R | C | I | I | A |
| 上线 / 移交 | A/R | C | I | I | C |

## 人力与席位

- 每个 R 必须落到 `kb/roster.md` 的席位；名册 `<待填>` = 配置缺口，不判“没人”。
- 外部依赖与客户责任单独列，不混进我方 RACI。
