# 事件记录模板（运维托管 / 维护服务）

> 层：交付模式 · 由 COO 主笔；每个 P1/P2 事件一条，月报从这里取数。

| 字段 | 内容 |
|---|---|
| 事件编号 | INC-YYYYMMDD-01 |
| 严重级别 | P1 / P2 / P3 |
| 开始 / 恢复时间 | |
| 影响范围 | 哪些客户 / 系统 / 功能 |
| 现象 | 客户可见的事实 |
| 处置 | 谁做了什么、何时升级 |
| 根因 | 已知 / 待查 |
| 沟通 | 客户通知时间与内容 |
| 复盘 | 改进项、owner、截止 |
| SLA 影响 | 是否计入赔付 |

## 复盘规则

- P1 必须复盘；P2 视重复性复盘；
- 改进项必须落到任务板，不能只写“注意”；
- 月报引用本表，不另写一套数字。
