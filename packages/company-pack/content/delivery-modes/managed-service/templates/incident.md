# Incident record template (managed operations / maintenance)

> Layer: delivery mode · COO leads; one record per P1/P2 incident; the monthly report takes data from here.

| Field | Content |
|---|---|
| Incident id | INC-YYYYMMDD-01 |
| Severity | P1 / P2 / P3 |
| Start / recovery time | |
| Impact | Which customers / systems / functions |
| Symptom | Customer-visible facts |
| Handling | Who did what, when escalated |
| Root cause | Known / under investigation |
| Communication | Customer notification time and content |
| Postmortem | Improvements, owner, deadline |
| SLA impact | Whether it counts toward compensation |

## Postmortem rules

- P1 always has a postmortem; P2 if recurring;
- Improvements must land on the task board, not just "noted";
- The monthly report references this table; it does not write a second set of numbers.
