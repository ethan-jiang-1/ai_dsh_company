# kb-setup/ · kb 的装配件

> 本目录只放**装配件**：`seed.json`（source → target）+ `guide.md`（seed 成 `kb/AGENTS.md`）+
> `run-bundle.md`（seed 成 `.dsh-company/README.md`）。**公司事实不进这里**——它们在 `company/`、
> `state/`、`product-types/`，本目录只描述"怎么装"。

- 新增/改名 kb 文件：改 `seed.json`，同步 `guide.md` 的表；`seed-integrity` 门禁会核对两边。
- 不允许：把 `policy-lines.md` 这类事实搬进来（层会消失，源/实例会混）。
- 本文件不 seed、不进 agent 上下文，只给维护者看。
