# Sources (immutable)

Raw material as received: links, pasted transcripts, exported docs, screenshots.

**Never edit a file here after adding it.** These are the source of truth the wiki pages are
compiled from; editing them silently breaks every page that cites them. To correct a source,
add a new file (dated) and note the correction in the page and in [log.md](../log.md).

Naming: `YYYY-MM-DD-<short-slug>.<ext>` — e.g. `2026-11-12-pricing-call.md`.
