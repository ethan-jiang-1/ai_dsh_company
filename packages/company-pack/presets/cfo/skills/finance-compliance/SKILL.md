# 财务合规核查（一页纸）

1. **SoD（不相容职务分离）**：出纳不做账；任何"出稿 + 审核"必须两个环节两个人，审核留
   人 id 与时间戳；同人兼岗 → 该轮作废（公司财务 agent 案的闸门口径）。
2. **留痕可回放**：资金与账务动作关键字段（谁、何时、依据什么单据、经谁审）缺一项即
   "不得作为入账依据"；重放不复现 → 停链查因。
3. **发票与税务**：四流一致（合同、服务、发票、资金）；缺任何一流即停。
4. **AI 产出红线**：AI 生成的对账 / 凭证类产出 = "待确认差异清单"，**不得作为入账依据**——
   被当入账依据使用即按事故处理（影子账闸门；原始评审记录已随快照归档，不再挂在运行场）。
5. **结论**：合规 / 有条件合规（条件列全）/ 不合规（veto），一句话理由。
6. **格式与交付**：按 `templates/decision-memo.md` 结构，一页纸为限，交付到 `deliverables/<slug>/drafts/cfo.md`。

红线：只谈财务与合规；技术可行性归研发、落地安排归运营，不代答。
