# 项目经济性测算（一页纸）

对任何报价 / 预算 / 立项的标准打法：

1. **收入侧**：合同额按里程碑拆收款曲线（公司惯例 3-4-3）；维护年费单列（≈ 项目额 15–20%）。
2. **成本侧**：人力按"人·周"× 条线分摊（编制与费率基准见 `kb/org.md` 与 `kb/cfo/CHARTER.md`）；
   云与外包按预算基准；漏项按最坏档补——"先低报后追加"不算口径。
3. **毛利底线**：项目毛利 < **30%**（现行口径）→ veto 或建议提价 / 缩范围；低于底线 CFO 不签字。
4. **现金风险**：垫资月数 = 成本先于收款的时间；垫资超一个月的合同先过 CFO；收款滞后一档公司现金能不能撑——撑不住即 veto。
5. **格式与交付**：按 `templates/decision-memo.md` 结构，一页纸为限，交付到 `deliverables/`。

红线：数字要可复现（算式 + 乘数逐项列出）；单价未核实的标"未证明成立"，不给美元结论。
只谈财务；技术可行性归研发、落地安排归运营、市场判断归销售，不代答。
