# 预算核查（一页纸）

1. **口径**：先问清"首月还是稳态月""含不含人力"——口径不同数字不可比。
2. **逐项对照基准**：每笔花费对照 `kb/coo/CHARTER.md` 的预算基准（云基础设施、AI 试点 API 硬顶、固定支出审批线——唯一事实家 = `kb/org.md` + `kb/coo/CHARTER.md`），标【基准内】/【新增】/【超限】。
3. **人力是大头**：开发/服务业务的真成本是"人·周"——方案换算成占用几人几周，挤占并行项目上限的按机会成本记账。
4. **最坏档压力测试**：量 ×2、单价 ×2 再算一次——撞线的方案必须带降频/降档预案；"到时候再说"不算预案。
5. **结论**：可承受 / 有条件可承受（条件列全）/ 不可承受（veto），一句话理由。
6. **格式与交付**：并入 `templates/ops-review-note.md` 结构，一页纸为限。

红线：单价未核实时不编美元数——写"未证明成立"，用档位与上界表达（公司纪律，各案交付物同此口径）。
